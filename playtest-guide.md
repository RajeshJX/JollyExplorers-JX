# JX starter project playtest

Use this short session to learn whether the first JX projects are fun, understandable, and useful. It is for an adult facilitator. Do not ask children for names, contact details, photos, or other personal information.

## Projects and intended learning

| Project | Try this | Learning idea |
| --- | --- | --- |
| Light the Lighthouse | Complete and reopen the circuit | Current needs a complete loop; an open switch breaks the path. |
| Build a Bridge | Add supports and vary the load | Supports help share weight and make structures more stable. |
| Rescue Rover | Program the rover, run the route, then debug it | Instructions have an order; testing and changing steps is useful. |

## 10–15 minute session

1. Let the child choose a project. Avoid explaining the controls first; see what they try.
2. If they get stuck, give one small hint and note what helped.
3. After play, ask: “What did you change?”, “What happened?”, and “What would you try next?”
4. Offer a different project and see whether they want to continue.
